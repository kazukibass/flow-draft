# 💡 Interactive Node Editor (ノード・フローチャートエディタ)

直感的でプロフェッショナルな操作性を備えた、ブラウザで動く軽量・高速なノードベースのフローチャート作成ツールです。開発者向けのスマートなショートカット、ミニマップ機能、無限キャンバス、レスポンシブなモバイルUIを搭載しています。

---

## ✨ 主な機能

* **接続の意味と閲覧モード**: 接続の種類・結果・説明を設定し、直接の接続・上流・下流・最短経路をハイライトできます。PC・モバイル共通です。[操作と保存仕様](docs/semantic-view-mode.md)

* **豊富なノードタイプ**: 開始/終了、プロセス、分岐、DB、API、ループなど、多様なユースケースに対応するプリセット。
* **プロ向けショートカット**: キーボードから手を離さずに、ノードの移動、削除、全選択、元に戻す/やり直すが可能。
* **ハイブリッド接続モード**: 固定切り替え（`C`キー）だけでなく、`Alt` / `Option` キーの長押しによるクイック接続にも対応。
* **高性能ミニマップ**: 右下にキャンバス全体を俯瞰できるミニマップをリアルタイム描画（テーマの配色に完全連動）。
* **履歴管理 (Undo / Redo)**: `Ctrl+Z` / `Ctrl+Y` による無制限の履歴バックアップとスナップショット機能。
* **インポート / エクスポート**: 作成した図面をJSON形式でローカルに保存・読み込み可能。
* **レスポンシブ対応**: PCだけでなく、スマホやタブレットのタッチ操作にも最適化された専用UI。

## ⌨️ キーボードショートカット (PC)

| キー | 操作内容 |
| :--- | :--- |
| **`C`** | 接続モードに切り替え（固定） |
| **`V`** / **`Esc`** | 選択モードに切り替え（デフォルト状態へ帰還） |
| **`Alt` (Win) / `Option` (Mac)** | **【長押し中のみ】** 一時的に接続モードを起動 |
| **`Delete`** / **`Backspace`** | 選択中のノードまたは接続線を削除 |
| **`Ctrl` + `A`** / **`Cmd` + `A`** | すべてのノードを選択 |
| **`Ctrl` + `Z`** / **`Cmd` + `Z`** | 元に戻す (Undo) ※ `Shift`同時押しで Redo |
| **`Ctrl` + `Y`** / **`Cmd` + `Y`** | やり直す (Redo) |
| **`F`** | 全てのノードが画面に収まるようにズーム・位置を自動調整 (Fit View) |
| **`矢印キー (← → ↑ ↓)`** | 選択中のノードを微調整移動 (8pxグリッド) |

## 🛠️ 基本的な操作方法

### 1. ノードの追加・編集
* キャンバス上の空いている場所を**ダブルクリック**すると、新しいノードが追加されます。
* ノードをクリックすると右側のプロパティパネルが開き、タイトルや内容の編集、ノードタイプの変更が可能です。

### 2. キャンバスの操作
* キャンバスの背景を**ドラッグ**することで、無限にパン（画面移動）ができます。
* **マウスホイール**（またはトラックパッドのピンチ操作）で自由な拡大・縮小（ズーム）に対応しています。

### 3. ノードの接続
* ノードの左右にある丸い「ポート」をドラッグ＆ドロップすることで、ノード同士を接続できます。
* または、`Alt`/`Option`キーを押しながらポートをクリック＆ドラッグすることでも素早く接続線を引くことができます。
