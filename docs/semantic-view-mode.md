# 接続の意味と閲覧モード

## 操作

1. 編集画面で接続線を選び、プロパティの「接続の意味」で種類・結果・説明を設定します。
2. PCは上部の「閲覧モード」、モバイルはメニュー内の「閲覧モード」で切り替えます。
3. ノードを押すか「経路・詳細」の始点を選びます。「直接の接続」「上流」「下流」「2点間の最短経路」を切り替えられます。
4. 接続の種類で絞り込めます。最短経路では終点も選びます。経路がない場合や同じ長さの候補が複数ある場合はその旨を表示します。
5. 詳細パネルは閉じてもハイライトを維持します。「経路・詳細」で再表示し、「編集に戻る」で通常の操作へ戻れます。

種類は未指定・制御・データ・イベント・依存。結果は未指定・通常・エラー・フォールバックを別に設定します。未指定の線は従来表示のままです。色だけでなく凡例・線種・接続一覧でも確認できます。

閲覧モードは誤編集を防ぐUIであり、アクセス制御ではありません。ここで示すのは図に記載した接続関係で、実行ログや実際の影響範囲を保証するものではありません。

## 保存契約

`schemaVersion: 1` と `semantics.connections[connectionId]` を追加します。既存のノード・接続・領域ID、ポート、曲線の調整を保持します。バージョンのない旧JSON・共有URL・保存データを正規化して読めます。新しいファイルを旧アプリへ読み込んだ場合、追加情報の維持は保証されません。

種類・結果・説明はUndo/Redo、JSON、共有URL、自動保存で保持します。フォーカス、経路選択、閲覧モード自体は保存しません。SVG/PNGは全体図と意味に応じた線種・色・ラベルを出力し、一時的な暗転や発光は含めません。

JSON読込は5MBまで。形式・ID・参照・種類・文字数・数値を適用前に検証します。不正なファイルは現在の図を置き換えません。壊れた自動保存は新規作成・テンプレート適用・有効なJSON読込まで上書きを抑止します。共有URLは暗号化ではないため、記載した説明も共有相手に渡ります。

外部JSONアダプター、実行ログ、アニメーション再生、領域の折りたたみは後続工程です。本リリースでは手入力した意味情報を扱います。

## 構成と検証

- `diagram-data.js`: 正規化、検証、接続の意味、表示スタイル。
- `graph-query.js`: 副作用のない有向グラフ探索。循環でも停止し、接続ID順で再現可能な最短経路を選びます。
- `view-mode.js`: 永続化しない閲覧状態とUI。編集用の選択状態と分離しています。
- `app.js` / `storage.js` / `export.js`: 既存の編集・保存・出力との接続。

実行環境は引き続きビルド不要のHTML/CSS/JavaScriptです。開発用テストのみNode.jsとjsdomを使います。

```sh
npm ci
npm test
python3 -m http.server 8765
```

CIではPRとmain pushで構文・単体・DOM操作テストを行い、main pushかつ検証成功時だけPagesへ配信します。公開artifactは製品ファイルのみに限定します。

DOMテストは実ブラウザの描画・ジェスチャーの代替ではありません。この実装時点でクラウドブラウザからローカルプレビューへのアクセスが拒否されたため、実際のPC表示・iOS Safariのタッチ/ピンチ・狭幅での重なりは実端末での確認が必要です。
